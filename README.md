# EKF Quiz Scoring

Scoring prototype for the **Retirement Plan Checkup** quiz (Evensky / Roar Media), published as a static page via GitHub Pages.

## Files

- `index.html` — self-contained prototype (HTML + CSS + JS, no build step).

## GitHub Pages

Served from the `main` branch, root folder. Once Pages is enabled (Settings → Pages → Deploy from a branch → `main` / `/ (root)`, requires repo admin), the page is available at:

https://webdevroarmedia.github.io/EKF-Quiz-Scoring/

## Workflow

Changes go through a task branch and a pull request against `main`; merges are done manually.
